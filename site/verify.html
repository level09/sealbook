Check a package yourself.

Someone gave you a Sealbook package. Drop the zip here and this page checks its hashes, chain, proofs, signatures and receipts in your browser. Nothing is uploaded.

    Prefer not to trust this page?

    Run Sealbook's offline verifier on a machine you control. It needs no network and no database. From a checkout of the source:

    unzip package.zip -d package
uv run python -m sealbook.ledger.verify_package package

    It also checks the timestamp authority's signature. Pin who you trust with --rp-id, --origin, --trusted-keys and --trusted-tsa. Check the cover's content credentials with c2patool package/package.svg.

    This page reads the file in your browser and sends it nowhere. It makes no third-party requests and has no analytics.
